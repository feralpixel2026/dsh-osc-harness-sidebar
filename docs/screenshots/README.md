| 文件 | 内容 | 用在 |

## 约定

- **PNG**，宽度 1200–1600 px；GitHub 与 npm 都会按容器宽度缩放，过宽只会浪费体积。
- **裁掉无关区域**（窗口边框、无关的其它应用），只留要说明的那块。
- 文件名用上面表里的名字；`README.md` 与 `README.en.md` 引用同一批文件，不需要各存一份。
- 内容必须是真实运行结果，不放示意图或占位图。

## 目录为空时

README 里对应位置的图片行保持注释状态，`tools/verify-readme-i18n.mjs` 会跳过注释内的链接，因此不会因缺图而失败。图片就位后取消 README 中的注释即可。
