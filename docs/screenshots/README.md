## 约定

- **PNG**，宽度 1200–1600 px；GitHub 与 npm 都按容器宽度缩放，过宽只会浪费体积。
- **裁掉无关区域**（窗口边框、其它应用），只留要说明的那块。
- 内容必须是真实运行结果，不放示意图。
- 换图时保持文件名不变，两张 README 都不必改。

## 新增截图时

在两张 README 的对应位置各加一行，然后在这里登记。**不要先提交注释掉的占位符**——注释对读者不可见，只会随着代码变化慢慢过时，还不如等图片到位再一起加。

## 关于校验脚本

开发本插件的工作区里有 `tools/verify-readme-i18n.mjs`（检查中英文 README 的图片引用是否一致）。它**不在本包内**，`files[]` 里也没有 `tools/`，所以装包的使用者拿不到它。
